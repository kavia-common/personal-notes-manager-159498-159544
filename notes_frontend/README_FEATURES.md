# Notes Frontend

- Two-pane layout:
  - Sidebar lists your notes (newest first)
  - Main area shows the selected note
- Features:
  - Create a note
  - Edit a note (auto-saved)
  - Delete a note
  - List notes
  - View note details (read-only viewer)
- Local-only persistence with `localStorage` (no backend required)
- Modern minimal light theme:
  - Primary: #1976d2
  - Accent: #ffb300
  - Secondary: #424242
